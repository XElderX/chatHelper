# Roadmap

These are proposed milestones, not promises or committed dates.

- **0.1.1:** address real-provider feedback, improve keyboard/focus accessibility, add conflict-recovery UX and broaden MySQL integration coverage.
- **0.2.x:** incremental paragraph analysis, stronger evaluation corpus, suggestions for longer documents, better selection behavior, offline draft recovery, authenticated multi-user foundation.
- **0.3.x:** Chrome / Firefox extension using an authenticated API; careful per-site permission and privacy controls.
- **0.4.x:** Android input integration with explicit user consent and secure account/session handling.
- **0.5.x:** desktop clients for Windows, macOS and Linux.
- **0.6.x:** iOS keyboard integration, within platform permission and background constraints.
- **1.0.0:** stable supported deployment model, migrations, recovery, cross-platform quality gates and security review.

Existing ChatGPT-account integration is conditional on an official authorized capability suitable for this project. No session-cookie access or subscription bypass is planned.

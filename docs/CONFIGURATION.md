# Configuration

Copy `.env.example` to `.env`; never commit `.env`. Run `php artisan config:clear` after changes. Restart the server. For configured cached deployments, regenerate with `php artisan config:cache`; do not run it during ordinary development.

| Variable | Default / purpose |
|---|---|
| APP_NAME | `chatHelper`; product name |
| APP_ENV | `local`; no public deployment is supported |
| APP_KEY | Generated by `php artisan key:generate`; protects sessions, analysis cache and ChatGPT credentials; preserve it on upgrades |
| APP_DEBUG | `false`; use `true` only when debugging privately |
| APP_URL | `http://127.0.0.1:8000`; canonical local URL |
| APP_LOCALE | `en` |
| LOG_CHANNEL | `single`; server error log |
| LOG_LEVEL | `error`; avoid document/request logging middleware |
| DB_CONNECTION | `mysql`; `sqlite` allowed for testing/demo |
| DB_HOST | `127.0.0.1` |
| DB_PORT | `3306` |
| DB_DATABASE | `chathelper`; absolute filename for SQLite |
| DB_USERNAME | `chathelper` |
| DB_PASSWORD | Local MySQL password |
| SESSION_DRIVER | `file`; session data under storage |
| SESSION_LIFETIME | `120` minutes |
| CACHE_STORE | `file`; rate limits and encrypted analysis cache |
| QUEUE_CONNECTION | `sync`; AI requests are synchronous HTTP calls |
| AI_PROVIDER | `openai`, `chatgpt`, or `mock`; initial/default choice, overridden by saved Settings selection |
| OPENAI_API_KEY | Secret server-side key; never available through settings API |
| OPENAI_MODEL | `gpt-4.1-mini`; configurable model with Responses structured-output support |
| OPENAI_TIMEOUT | `30` seconds; connect timeout is 10 seconds |
| OPENAI_TEMPERATURE | Empty/omitted by default; numeric value only when the selected model supports it |
| OPENAI_REASONING_EFFORT | Empty/omitted by default; set only for models that support reasoning configuration. Do not set for the default GPT-4.1 mini model |
| AI_ANALYSIS_DEBOUNCE_MS | `700`; minimum 300 milliseconds |
| AI_LIVE_ANALYSIS_ENABLED | `true`; initializes first-run DB setting, not an override of a saved user preference |
| AI_CACHE_TTL | `300` seconds; set `0` to avoid retaining results |
| AI_RATE_LIMIT | `30` AI calls per minute across the local user |

The general API limit is 180 requests/minute. Rewrites are not cached. There are no automatic retries that might duplicate billable requests. Browser cancellation discards the response; it cannot guarantee cancellation of a provider request already in progress.

## Official OpenAI setup

Create a project API key at https://platform.openai.com/api-keys and configure API billing/usage limits for that project. Paste the key only into the server's `.env` file. Never paste it into Vue code, a screenshot or a source-controlled file.

API usage is billed separately from ChatGPT subscriptions. For eligible subscription usage, use **Continue with ChatGPT** in Settings. This uses official OAuth authorization; no ChatGPT password, session cookie, API key or client secret is pasted into chatHelper.

The callback is `http://127.0.0.1:<port>/auth/chatgpt/callback`. Keep the app running on the same port during sign-in. Authorization attempts expire after ten minutes. Select a model from the account-specific list after connecting; `OPENAI_MODEL`, temperature and reasoning environment options apply only to API-key mode. Switching providers is an explicit action. Subscription failures never trigger API-key billing.

Keep `SESSION_DRIVER=file`, `SESSION_SAME_SITE=lax` (default), and a persistent cache store supporting atomic locks (`file` is the local default). Do not use an in-memory/array cache outside tests: pending OAuth attempts and refresh locks must survive requests. Use one local server instance. Credentials are encrypted in `chatgpt_accounts`; stable account registrations and the host identifier remain after sign-out for reauthorization. See [upgrade instructions](UPGRADE_0.2.md) before moving installations.

The default `gpt-4.1-mini` was checked against official model documentation during implementation. It supports the Responses API and structured outputs. Optional generation controls are passed only when explicitly configured; verify model compatibility before changing them. A configured key is not a successful connectivity check.

## Privacy

The UI discloses when text is sent externally. Disable Live analysis in Settings to stop automatic requests. Manual Analyze now, Rewrite and Explain remain explicit AI actions. The mock provider sends nothing externally.

The backend uses `store:false`; provider policy may still allow safety/abuse retention. The local database contains unencrypted documents. Analysis cache values are encrypted using APP_KEY, with hashed cache identifiers. Protect local files and backups, and preserve APP_KEY. Changing APP_KEY makes stored credentials unreadable. Preserve the original key; if it is lost, credentials must be cleared locally and accounts reauthorized. Clear analysis cache after a deliberate key rotation: `php artisan cache:clear`.
